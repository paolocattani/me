# Public writing

Paolo's public voice. The DNA is in the repo, not in this file.

## Before anything else

Read, in order:

1. [docs/knowledge/VOICE.md](../../../docs/knowledge/VOICE.md)
2. [docs/knowledge/CHANNELS.md](../../../docs/knowledge/CHANNELS.md)
3. [docs/knowledge/SERIES.md](../../../docs/knowledge/SERIES.md)
4. The matching row in [docs/STATUS.md](../../../docs/STATUS.md)

If those files contradict a habit from another skill, the docs win.

This skill is a fork of process, not of LinkedIn formula packs. It takes:

- outline-then-write from Giova `documentation-writer`
- read-only pile + grounding from `writing-shape`
- AI-tell cuts from `unslop` (already copied into `VOICE.md`)
- native post, no bait, from substance-first LinkedIn writers

It does not use hook-formula menus or engagement multipliers.

## Pile

Treat the source as a quarry. Typical piles:

- A Notion page in [LinkedIn post ideas](https://app.notion.com/p/6cc419d5a62e477695f7a94ec0e3513c)
- A Cursor transcript or commit range the Notion `Fonte` field names
- An existing sister draft listed in `SERIES.md`

Do not edit the pile. Do not fill gaps with invented facts. If the next beat needs a fact the pile does not have, name the gap and stop.

## Workflow

1. **Channel and piece.** Name LinkedIn, blog, Substack, or a combination. Name the series row if one exists.
2. **Prerequisites.** What the reader already knows. For LinkedIn, assume ERP + docs + "an assistant in the product". Do not assume repo layout.
3. **Outline.** For a new essay or flagship, show the outline (or two opening lines for LinkedIn) and wait. For a tiny edit of an approved draft, skip this gate.
4. **Write.** One piece per channel depth. Same argument, different cut. Follow `CHANNELS.md`.
5. **Voice pass.** Run the tests at the bottom of `VOICE.md`.
6. **Hand to Paolo.** Do not publish LinkedIn, R2, Substack, or Notion status `pronta` until he says so.
7. **After a correction.** Encode it in `VOICE.md` the same turn. If it changes a channel rule or a series row, update that file and the `STATUS.md` cell. Replace the sentence. Do not append.

## LinkedIn

- Native. No URL in a flagship.
- First two lines earn "see more". Prefer the lesson at the top, then the story.
- Strip paths, hashes, ticket ids.
- No "ne ho già scritto" unless that post is public (`SERIES.md` status).
- Close on the lesson. No "Agree?".

Ready-to-ship copy for series row 1 lives in [examples.md](examples.md). Prefer editing that over rewriting from scratch.

## Blog

Canonical long form. Frontmatter as in `CHANNELS.md`. Italian. Teach with a path only when the path is the point.

## Substack

Paste the blog essay. Add a 4–6 line "why this week" intro and a canonical URL at the end. If the publication does not exist yet, stop at paste-ready text.

## Done when

- The draft obeys `VOICE.md`
- Every name and number traces to the pile
- Outline was approved (or the change was a tiny edit)
- Docs are updated if Paolo changed the style or a row shipped
